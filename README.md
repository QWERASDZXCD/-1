# Zombie Shooter 3D

Godot 4.3+ 로 만든 3D 탑다운 좀비 슈터.

## 실행
1. Godot 4.3 이상 설치 (https://godotengine.org)
2. 프로젝트 매니저에서 이 폴더의 `project.godot` 가져오기
3. F5 (실행)

## 조작
- 이동: WASD / 방향키
- 조준: 마우스 (캐릭터가 마우스 쪽을 바라봄)
- 발사: 마우스 왼쪽 버튼 (누르고 있으면 연사) 또는 Space
- 재장전: R (탄약이 0이면 자동)
- 무기 교체: 숫자키 1~4 또는 마우스 휠 (1 권총, 2 기관단총, 3 샷건, 4 저격총)
- 게임 오버 후 재시작: Enter
